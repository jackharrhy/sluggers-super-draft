# Allow trading captain if valid captain remains

Relax the captain trading restriction. Allow trading your captain if you'll still have a captain-eligible player after the trade. Auto-assign new captain on trade acceptance.

## Acceptance Criteria

Captain can be included in trades if the team will have another captain-eligible player post-trade. New captain is auto-assigned.
