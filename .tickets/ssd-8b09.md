# 'Try out' sandbox lineup view

Sandbox mode to experiment with lineups and chemistry without saving. Prefill from your team if logged in, clear button, load any team's lineup, click-to-add player list.

## Acceptance Criteria

User can build a lineup in a sandbox, see the field preview, and optionally load a team's existing lineup. No data is saved.
