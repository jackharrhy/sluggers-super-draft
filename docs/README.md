# Documentation map

- `game-adapter/`: durable Sluggers memory, build, menu, telemetry, and acceptance findings.
- `research/`: recorded Dolphin and community-tool research.
- `plans/`: original Sluggers Super Draft application plans.
- `archive/starworks-platform/`: preserved multi-league platform plans, migration
  guides, support policy, and operations documentation.

The platform source formerly at root `web/`, `runner/`, `contracts/`, `demo/`,
and `deploy/` now lives together under `experiments/starworks-platform/`.
Commands and source paths in the research and adapter documents refer to that
experiment unless explicitly marked repository-relative. Local ignored research
inputs remain at repository-root `research/`; they are not tracked documentation.

Historical plans describe their original layout and status; they do not define
the direction of future work. See the [repository README](../README.md) for the
current boundaries.
